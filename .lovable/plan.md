# Academy Homepage Redesign

## Goal
Refocus the existing homepage into AmigoXcel Academy around four conversion priorities: first impression, course choice, trust, and one clear enquiry action.

## Scope
- Preserve the existing logo, core color identity, contact submission behavior, Resume Tailor route, and genuine testimonial wording.
- Replace the broad agency homepage narrative with an Academy-focused journey: understand, trust, choose, act.
- Build a concise hero with the four-stage career progression and one primary action: “See Your Best Fit”.
- Present the four supplied courses as fast-scanning, visually distinct choices with short copy and “Learn More” actions.
- Place the four existing testimonials near course selection and the enquiry action.
- Rework the final call-to-action and existing form around “Find Your Best Fit”, keeping fields easy to complete.
- Add a collapsed “See Comparison” area and a short FAQ containing only the supplied questions.
- Remove homepage sections and navigation items that distract from this focused path.
- Update homepage metadata and visible branding to “AmigoXcel Academy”.

## Technical Details
- Reuse the existing React, Tailwind, design tokens, Button, form validation, and Lovable Cloud insert.
- Use semantic colors and restrained motion; ensure mobile-first layouts and accessible disclosure/form controls.
- Keep `/resume-tailor` available without changing its feature behavior.

## Validation
- Check desktop and mobile layouts, disclosure interactions, navigation, form opening, and browser errors.
